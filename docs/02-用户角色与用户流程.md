# IERepair 平台 — 用户角色与用户流程

> 文档版本：v1.0  
> 最后更新：2026-04-01

---

## 一、角色定义与权限边界

### 1.1 角色总览

| 角色 | 标识 | 登录方式 | 核心诉求 |
|------|------|----------|----------|
| 终端用户 | Consumer | 手机号 / Google / Apple 登录 | 找到附近门店、买配件、预约维修、管理会员 |
| 加盟门店 | Merchant | 账号 + 密码 | 接收订单、管理商品价格、查看结算 |
| 供应商 | Supplier | 账号 + 密码 | 维护商品信息、接收采购建议、发货 |
| 平台管理员 | SuperAdmin | 账号 + 密码 + 2FA | 管理全平台、审核商品、配置规则 |

---

## 二、终端用户（Consumer）流程

### 2.1 注册 / 登录流程

```
进入平台首页
    │
    ├── 游客模式（可搜索浏览，不可下单）
    │
    └── 注册 / 登录
            ├── 手机号 + OTP 验证码
            ├── Google 一键登录
            └── Apple 一键登录
                    │
                    └── 登录成功 → 进入个人中心
```

---

### 2.2 搜索商品流程

```
首页搜索框
    │
    ├── 输入关键词（如："iPhone 15 屏幕" / "Samsung case"）
    │       │
    │       └── 输入 Eircode（爱尔兰邮编，如 D02 XY45）
    │               │
    │               └── 系统返回：
    │                       ├── 附近门店列表（按距离排序）
    │                       ├── 每家门店该商品的价格
    │                       └── 门店评分、营业状态
    │
    └── 按品类浏览（手机壳 / 充电器 / 换屏服务 / 等）
```

**搜索结果展示规则：**
- 默认按 Eircode 距离从近到远排序
- 同一商品在不同门店的价格并排展示（比价视图）
- 门店营业状态实时显示（营业中 / 休息中 / 今日关店）
- 无库存的门店该商品置灰并注明"暂无库存"

---

### 2.3 商品购买流程

```
选择商品 → 选择门店
    │
    ├── 选择取货方式
    │       ├── 到店自取（选择时间段）
    │       └── 邮寄配送（输入收货地址）
    │
    ├── 确认订单
    │       ├── 商品明细
    │       ├── 门店信息
    │       └── 价格明细（含平台服务费展示）
    │
    ├── 选择支付方式
    │       ├── 线上支付 → Stripe（信用卡 / 借记卡 / Apple Pay / Google Pay）
    │       └── 到店支付 → 刷卡机 / 现金（下单时预留，到店完成支付）
    │
    ├── 支付成功
    │       ├── 系统自动发 SMS 给用户（订单确认）
    │       ├── 系统自动发 SMS / 站内通知 给加盟门店（新订单提醒）
    │       └── 订单状态：待处理
    │
    └── 门店确认接单 → 订单状态：处理中
            │
            ├── 到店自取：用户到店 → 门店核销 → 完成
            └── 邮寄：门店发货 → 填写快递单号 → 用户收货确认 → 完成
```

**支付说明：**
- 线上支付：Stripe 收款，平台扣除抽成后，余额 T+7 结算给门店
- 到店支付：门店收款，平台在月度账单中向门店收取抽成

---

### 2.4 维修预约流程

```
选择"维修服务"
    │
    ├── 输入手机品牌 / 型号（如：iPhone 14 Pro）
    ├── 选择故障类型（换屏 / 换电池 / 进水维修 / 其他）
    ├── 输入 Eircode → 系统展示附近可提供该维修服务的门店
    │
    ├── 选择门店
    ├── 选择预约时间段（门店设置的可用时间）
    ├── 填写备注（可选）
    │
    ├── 确认预约
    │       ├── 是否使用维修会员权益（有会员则自动抵扣）
    │       └── 不使用会员 → 到店付款 or 线上预付定金（可选）
    │
    ├── 预约成功
    │       ├── 系统 SMS → 用户（预约确认 + 门店地址 + 时间）
    │       └── 系统 SMS / 通知 → 门店（新预约提醒）
    │
    └── 门店接受预约 → 用户到店 → 门店完成维修 → 核销订单
            │
            ├── 会员抵扣：系统扣除会员次数，平台与门店结算维修费
            └── 非会员：到店付款（线下），门店录入实际收费金额
```

---

### 2.5 购买维修会员流程

```
个人中心 → 会员计划
    │
    ├── 浏览套餐（基础版 / Plus / 全保版）
    ├── 选择套餐 → 确认购买
    ├── Stripe 在线支付
    ├── 支付成功
    │       ├── 生成会员卡（含有效期、剩余次数）
    │       └── SMS 确认通知
    │
    └── 使用会员：在维修预约时自动识别并展示可用权益
```

---

### 2.6 订单售后流程

```
我的订单 → 选择订单
    │
    ├── 申请退款（仅限未发货 / 未到店核销的订单）
    │       └── 平台审核 → 通过 → Stripe 原路退款（3~5 工作日）
    │
    └── 投诉 / 纠纷
            └── 提交纠纷 → 平台客服介入 → 裁决处理
```

## 三、加盟门店（Merchant）流程

### 3.1 入驻申请流程

```
访问平台官网 → 申请加盟
    │
    ├── 填写门店信息
    │       ├── 店主姓名、联系方式
    │       ├── 门店名称、地址、Eircode
    │       ├── 营业执照 / 注册信息（上传）
    │       └── 营业时间
    │
    ├── 提交申请 → 平台管理员审核（1~3 个工作日）
    │
    ├── 审核通过
    │       ├── 系统自动发送账号密码（SMS + Email）
    │       └── 引导完成门店配置
    │
    └── 审核不通过 → 通知原因 → 可修改后重新提交
```

---

### 3.2 选品与定价流程

```
登录商家后台 → 商品管理
    │
    ├── 浏览产品母库（按品类筛选）
    ├── 勾选要销售的商品（支持批量选择）
    ├── 设置本店售价
    │       ├── 系统显示：平台建议零售价 / 平台最低售价
    │       ├── 不得低于平台设定的最低售价
    │       └── 可高于建议价（自行决定利润空间）
    │
    └── 保存上架 → 商品立即在用户端该门店页展示
```

---

### 3.3 接单与处理流程

```
新订单到达 → SMS + 后台通知提醒
    │
    ├── 登录后台 → 订单管理
    ├── 查看订单详情（商品、用户联系方式、取货方式）
    │
    ├── 接单（确认）
    │       ├── 到店自取订单 → 备货 → 等待用户到店 → 核销（扫码 or 订单号）
    │       └── 邮寄订单 → 备货 → 填写快递信息 → 发货
    │
    └── 拒单（需填写原因，系统通知用户并退款）
```

---

### 3.4 采购建议流程

```
系统自动分析：
    ├── 门店已上架商品的近期销售趋势
    ├── 当前库存预警（平台侧库存数据）
    └── 生成采购建议清单（每周推送）

门店收到采购建议
    │
    ├── 查看建议清单（品名、建议采购量、供应商报价）
    ├── 确认采购 → 联系供应商 / 平台代采
    └── 忽略（不做强制要求）
```

> 注：门店本身不维护库存数字，平台通过供应商库存数据 + 销售速率模型为门店生成采购建议，确保货源充足。

---

### 3.5 结算查询流程

```
后台 → 财务结算
    │
    ├── 查看本月销售流水
    ├── 查看平台抽成明细（按订单）
    ├── 查看应结金额 / 已结金额
    └── 下载对账单（PDF / CSV）
```

---

## 四、供应商（Supplier）流程

### 4.1 商品入库流程

```
登录供应商后台 → 商品管理
    │
    ├── 提交新商品申请
    │       ├── 填写：品名、品牌、型号适配、规格、图片、批发价
    │       └── 提交平台审核
    │
    ├── 平台管理员审核
    │       ├── 品类合规审核（是否属于手机相关品类）
    │       ├── 数据完整性审核（图片、描述、价格）
    │       └── 通过 → 进入产品母库
    │
    └── 审核不通过 → 退回原因 → 修改重提
```

### 4.2 库存与订单管理

```
接收采购/发货通知
    │
    ├── 查看待处理采购单
    ├── 更新库存数量
    ├── 确认发货 → 填写快递信息
    └── 查看历史交易记录 & 回款状态
```

---

## 五、平台管理员（SuperAdmin）流程

### 5.1 门店审核

```
待审核列表 → 查看申请资料
    │
    ├── 核验营业执照真实性
    ├── 确认地址 / Eircode 有效
    └── 通过 / 拒绝（填写原因）
```

### 5.2 商品母库管理

```
供应商提交新品 → 审核队列
    │
    ├── 品类合规检查（白名单制）
    ├── 数据质量检查（图片分辨率、描述完整性）
    ├── 价格合理性检查
    └── 通过 → 上架母库 / 拒绝 → 退回供应商
```

### 5.3 抽成与结算管理

```
每月结算周期到达
    │
    ├── 系统自动汇总各门店销售数据
    ├── 按规则计算抽成
    ├── 生成门店结算账单（自动推送给门店）
    ├── 线上支付订单：Stripe 自动划转（扣除抽成后打款）
    └── 到店支付订单：生成应收账单 → 门店通过平台转账支付抽成
```

### 5.4 会员计划结算

```
维修订单完成核销
    │
    ├── 系统识别是否使用会员权益
    ├── 按预设比例计算门店应得维修服务费
    └── 纳入月度结算账单
```

## 六、SMS 通知触发清单

| 触发事件 | 接收方 | 内容摘要 |
|----------|--------|----------|
| 用户注册 OTP | 用户 | 验证码 |
| 商品订单创建成功 | 用户 + 门店 | 订单号、商品、取货方式 |
| 门店确认接单 | 用户 | 预计备货时间 |
| 订单发货 | 用户 | 快递单号、预计到达 |
| 维修预约成功 | 用户 + 门店 | 预约时间、地址、手机型号 |
| 维修预约取消 | 用户 | 取消确认 |
| 门店拒单 | 用户 | 原因 + 退款告知 |
| 退款成功 | 用户 | 退款金额、到账时间 |
| 会员购买成功 | 用户 | 套餐名称、有效期、剩余次数 |
| 采购建议生成 | 门店 | 提醒查看后台采购建议 |
| 月度结算账单生成 | 门店 | 提醒查看后台对账单 |
| 门店审核通过 | 门店 | 账号信息 |
