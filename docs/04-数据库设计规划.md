# IERepair 平台 — 数据库设计规划

> 文档版本：v1.0  
> 数据库：PostgreSQL  
> 最后更新：2026-04-01

---

## 一、设计原则

- 使用 PostgreSQL，利用 PostGIS 扩展支持门店地理位置查询
- 所有主键使用 UUID（防止枚举攻击）
- 所有表包含 `created_at` / `updated_at` / `deleted_at`（软删除）
- 货币金额统一用整数存储（以 **分/cent** 为单位，避免浮点精度问题）
- 枚举类型统一用字符串常量（便于可读性和扩展）

```
├── 用户模块        users / user_addresses / user_sessions
```

## 三、详细表设计

### 3.1 用户模块

#### `users` — 终端用户

```sql
CREATE TABLE users (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    phone           VARCHAR(20) UNIQUE,           -- 手机号（国际格式）
    email           VARCHAR(255) UNIQUE,
    full_name       VARCHAR(100),
    avatar_url      VARCHAR(500),
    auth_provider   VARCHAR(20) DEFAULT 'phone',  -- phone | google | apple
    auth_provider_id VARCHAR(255),                -- OAuth 第三方 ID
    is_active       BOOLEAN DEFAULT TRUE,
    last_login_at   TIMESTAMPTZ,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ
);
```

#### `user_addresses` — 用户收货地址

```sql
CREATE TABLE user_addresses (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id     UUID NOT NULL REFERENCES users(id),
    label       VARCHAR(50),              -- 如：家、公司
    full_name   VARCHAR(100),
    phone       VARCHAR(20),
    address_line1 VARCHAR(255),
    address_line2 VARCHAR(255),
    city        VARCHAR(100),
    eircode     VARCHAR(10),
    is_default  BOOLEAN DEFAULT FALSE,
    created_at  TIMESTAMPTZ DEFAULT NOW(),
    updated_at  TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.2 门店模块

#### `merchants` — 加盟门店

```sql
CREATE TABLE merchants (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    owner_name      VARCHAR(100) NOT NULL,
    shop_name       VARCHAR(200) NOT NULL,
    email           VARCHAR(255) UNIQUE NOT NULL,
    phone           VARCHAR(20),
    address_line1   VARCHAR(255),
    address_line2   VARCHAR(255),
    city            VARCHAR(100),
    eircode         VARCHAR(10),
    location        GEOGRAPHY(POINT, 4326),       -- PostGIS 地理坐标（由 Eircode 解析）
    logo_url        VARCHAR(500),
    description     TEXT,
    status          VARCHAR(20) DEFAULT 'pending', -- pending | active | suspended | closed
    iban            VARCHAR(50),                   -- 银行账户，用于结算
    commission_rate NUMERIC(5,2),                  -- 覆盖全局抽成率（可为空，为空则用全局规则）
    password_hash   VARCHAR(255) NOT NULL,
    last_login_at   TIMESTAMPTZ,
    approved_at     TIMESTAMPTZ,
    approved_by     UUID REFERENCES admin_users(id),
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ
);

CREATE INDEX idx_merchants_location ON merchants USING GIST(location);
CREATE INDEX idx_merchants_status ON merchants(status);
```

#### `merchant_hours` — 门店营业时间

```sql
CREATE TABLE merchant_hours (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    merchant_id UUID NOT NULL REFERENCES merchants(id),
    day_of_week SMALLINT NOT NULL,    -- 0=周日, 1=周一 ... 6=周六
    open_time   TIME,
    close_time  TIME,
    is_closed   BOOLEAN DEFAULT FALSE -- 当天休息
);
```

#### `merchant_services` — 门店提供的维修服务

```sql
CREATE TABLE merchant_services (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    merchant_id     UUID NOT NULL REFERENCES merchants(id),
    service_id      UUID NOT NULL REFERENCES repair_services(id), -- 来自平台服务库
    price_cents     INTEGER,           -- 该门店对此服务的定价（分）
    is_available    BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(merchant_id, service_id)
);
```

### 3.4 产品模块

#### `product_categories` — 品类（白名单树形结构）

```sql
CREATE TABLE product_categories (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    parent_id   UUID REFERENCES product_categories(id),
    name        VARCHAR(100) NOT NULL,
    slug        VARCHAR(100) UNIQUE NOT NULL,  -- URL 友好标识
    sort_order  SMALLINT DEFAULT 0,
    is_active   BOOLEAN DEFAULT TRUE,
    created_at  TIMESTAMPTZ DEFAULT NOW(),
    updated_at  TIMESTAMPTZ DEFAULT NOW()
);
```

#### `products` — 产品母库

```sql
CREATE TABLE products (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_id     UUID NOT NULL REFERENCES suppliers(id),
    category_id     UUID NOT NULL REFERENCES product_categories(id),
    name            VARCHAR(300) NOT NULL,
    brand           VARCHAR(100),
    description     TEXT,
    images          JSONB,              -- ["url1", "url2", ...]
    compatible_models JSONB,            -- ["iPhone 14", "Samsung S23", ...]
    status          VARCHAR(20) DEFAULT 'pending_review',
                                        -- pending_review | active | rejected | inactive
    rejection_reason TEXT,
    reviewed_by     UUID REFERENCES admin_users(id),
    reviewed_at     TIMESTAMPTZ,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ
);

CREATE INDEX idx_products_category ON products(category_id);
CREATE INDEX idx_products_status ON products(status);
CREATE INDEX idx_products_brand ON products(brand);
```

#### `product_skus` — 商品 SKU（规格变体）

```sql
CREATE TABLE product_skus (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    product_id      UUID NOT NULL REFERENCES products(id),
    sku_code        VARCHAR(100) UNIQUE,
    attributes      JSONB,             -- {"color": "Black", "size": "6.1 inch"}
    wholesale_price_cents INTEGER NOT NULL,   -- 供应商批发价（分）
    min_retail_price_cents INTEGER NOT NULL,  -- 平台设定最低零售价（分）
    suggest_retail_price_cents INTEGER,       -- 平台建议零售价（分）
    stock_quantity  INTEGER DEFAULT 0,
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);
```

#### `merchant_products` — 门店已选品及定价

```sql
CREATE TABLE merchant_products (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    merchant_id     UUID NOT NULL REFERENCES merchants(id),
    sku_id          UUID NOT NULL REFERENCES product_skus(id),
    price_cents     INTEGER NOT NULL,   -- 该门店实际售价（分）
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(merchant_id, sku_id)
);

CREATE INDEX idx_merchant_products_merchant ON merchant_products(merchant_id);
CREATE INDEX idx_merchant_products_sku ON merchant_products(sku_id);
```

#### `repair_services` — 维修服务库（平台维护）

```sql
CREATE TABLE repair_services (

    name            VARCHAR(200) NOT NULL,       -- 如：换屏、换电池

    description     TEXT,
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
```

### 3.5 订单模块

#### `orders` — 商品订单

```sql
CREATE TABLE orders (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_no        VARCHAR(30) UNIQUE NOT NULL,  -- 可读订单号，如：IE20260401-00001
    user_id         UUID NOT NULL REFERENCES users(id),
    merchant_id     UUID NOT NULL REFERENCES merchants(id),
    status          VARCHAR(30) DEFAULT 'pending_payment',
                    -- pending_payment | paid | merchant_confirmed | 
                    -- ready_pickup | shipped | completed | cancelled | refunded
    fulfillment_type VARCHAR(20) NOT NULL,        -- pickup | delivery
    pickup_slot     TIMESTAMPTZ,                  -- 到店自取预约时间
    delivery_address JSONB,                       -- 收货地址快照
    subtotal_cents  INTEGER NOT NULL,             -- 商品合计（分）
    shipping_cents  INTEGER DEFAULT 0,            -- 运费（分）
    total_cents     INTEGER NOT NULL,             -- 实付总额（分）
    commission_cents INTEGER,                     -- 平台抽成（分）
    payment_method  VARCHAR(20),                  -- stripe | in_store_card | in_store_cash
    payment_status  VARCHAR(20) DEFAULT 'unpaid', -- unpaid | paid | refunded
    stripe_payment_intent_id VARCHAR(255),
    notes           TEXT,
    cancelled_reason TEXT,
    completed_at    TIMESTAMPTZ,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_orders_user ON orders(user_id);
CREATE INDEX idx_orders_merchant ON orders(merchant_id);
CREATE INDEX idx_orders_status ON orders(status);
CREATE INDEX idx_orders_created_at ON orders(created_at);
```

#### `order_items` — 订单明细

```sql
CREATE TABLE order_items (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id        UUID NOT NULL REFERENCES orders(id),
    sku_id          UUID NOT NULL REFERENCES product_skus(id),
    product_name    VARCHAR(300) NOT NULL,  -- 下单时快照
    sku_attributes  JSONB,                  -- 规格快照
    quantity        INTEGER NOT NULL,
    unit_price_cents INTEGER NOT NULL,      -- 下单时快照单价
    total_cents     INTEGER NOT NULL
);
```

#### `order_status_logs` — 订单状态变更记录

```sql
CREATE TABLE order_status_logs (
    id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    order_id    UUID NOT NULL REFERENCES orders(id),
    from_status VARCHAR(30),
    to_status   VARCHAR(30) NOT NULL,
    operator_type VARCHAR(20),  -- user | merchant | system | admin
    operator_id UUID,
    notes       TEXT,
    created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.6 维修预约模块

#### `repair_bookings` — 维修预约

```sql
CREATE TABLE repair_bookings (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    booking_no      VARCHAR(30) UNIQUE NOT NULL,
    user_id         UUID NOT NULL REFERENCES users(id),
    merchant_id     UUID NOT NULL REFERENCES merchants(id),
    service_id      UUID NOT NULL REFERENCES repair_services(id),
    device_brand    VARCHAR(100),
    device_model    VARCHAR(100),
    fault_description TEXT,
    booking_time    TIMESTAMPTZ NOT NULL,          -- 预约时间
    status          VARCHAR(30) DEFAULT 'pending_confirm',
                    -- pending_confirm | confirmed | in_progress | 
                    -- completed | cancelled | no_show
    membership_id   UUID REFERENCES user_memberships(id),  -- 使用的会员
    quoted_price_cents INTEGER,                    -- 门店报价（分）
    actual_price_cents INTEGER,                    -- 实际收费（完成后填写）
    payment_method  VARCHAR(20),                   -- 到店付款方式
    notes           TEXT,
    cancelled_reason TEXT,
    completed_at    TIMESTAMPTZ,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_repair_bookings_merchant ON repair_bookings(merchant_id);
CREATE INDEX idx_repair_bookings_user ON repair_bookings(user_id);
CREATE INDEX idx_repair_bookings_time ON repair_bookings(booking_time);
```

### 3.7 会员模块

#### `membership_plans` — 会员套餐配置

```sql
CREATE TABLE membership_plans (

    benefits        JSONB NOT NULL,
    -- 示例：
    -- {
    --   "screen_replacements": 1,      // 免费换屏次数
    --   "battery_replacements": 0,

    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
```

#### `user_memberships` — 用户购买的会员

```sql
CREATE TABLE user_memberships (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id         UUID NOT NULL REFERENCES users(id),
    plan_id         UUID NOT NULL REFERENCES membership_plans(id),
    order_id        UUID REFERENCES orders(id),    -- 购买来源订单（如适用）
    stripe_payment_intent_id VARCHAR(255),
    starts_at       TIMESTAMPTZ NOT NULL,
    expires_at      TIMESTAMPTZ NOT NULL,
    status          VARCHAR(20) DEFAULT 'active',  -- active | expired | cancelled
    -- 剩余权益快照（使用后递减）
    remaining_benefits JSONB NOT NULL,
    price_paid_cents INTEGER NOT NULL,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_user_memberships_user ON user_memberships(user_id);
CREATE INDEX idx_user_memberships_expires ON user_memberships(expires_at);
```

#### `membership_usage_logs` — 会员权益使用记录

### 3.8 财务模块

#### `commission_rules` — 抽成规则

```sql
CREATE TABLE commission_rules (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name            VARCHAR(100),
    category_id     UUID REFERENCES product_categories(id), -- 为空=全局规则
    merchant_id     UUID REFERENCES merchants(id),           -- 为空=通用规则
    rate            NUMERIC(5,2) NOT NULL,    -- 如 10.00 表示 10%
    effective_from  DATE NOT NULL,
    effective_to    DATE,
    is_active       BOOLEAN DEFAULT TRUE,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);
```

#### `settlements` — 结算周期

```sql
CREATE TABLE settlements (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    merchant_id     UUID NOT NULL REFERENCES merchants(id),
    period_start    DATE NOT NULL,
    period_end      DATE NOT NULL,
    total_gmv_cents INTEGER DEFAULT 0,          -- 周期内 GMV
    total_commission_cents INTEGER DEFAULT 0,   -- 平台应收抽成
    total_payout_cents INTEGER DEFAULT 0,       -- 门店应得（线上支付部分）
    membership_payout_cents INTEGER DEFAULT 0,  -- 会员维修服务费
    status          VARCHAR(20) DEFAULT 'pending',
                    -- pending | processing | completed | disputed
    stripe_transfer_id VARCHAR(255),
    settled_at      TIMESTAMPTZ,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);
```

#### `settlement_items` — 结算明细

```sql
CREATE TABLE settlement_items (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    settlement_id   UUID NOT NULL REFERENCES settlements(id),
    reference_type  VARCHAR(20) NOT NULL,    -- order | repair_booking | membership_usage
    reference_id    UUID NOT NULL,
    amount_cents    INTEGER NOT NULL,         -- 正数=应付门店，负数=应收抽成
```

## 五、索引与性能策略

| 查询场景 | 索引策略 |
|----------|----------|
| 按 Eircode 搜索附近门店 | PostGIS GIST 空间索引（`merchants.location`）|
| 搜索某 SKU 在附近门店的售价 | `merchant_products(sku_id)` + 门店 location JOIN |
| 用户订单列表 | `orders(user_id, created_at DESC)` 复合索引 |
| 门店订单管理 | `orders(merchant_id, status, created_at DESC)` 复合索引 |
| 产品母库全文搜索 | PostgreSQL `tsvector` 全文索引（`products.name`）|
| 会员有效期查询 | `user_memberships(user_id, expires_at)` |
