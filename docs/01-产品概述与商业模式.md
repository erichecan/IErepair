> 文档版本：v1.0  
> 编写语言：中文  
> 最后更新：2026-04-01

## 一、产品背景

客户在爱尔兰本地经营 3 家手机维修门店，涵盖手机维修、配件销售、贴膜、手机壳等业务。  
目标是以这 3 家门店为起点，打造一套可向爱尔兰全境 **3000+ 家同类门店** 免费开放的 SaaS 平台，通过平台流量聚合和供应链整合，形成可持续的商业模型。

---

## 二、平台定位

| 维度 | 描述 |
|------|------|
| **平台名称** | IERepair（暂定） |
| **行业垂直** | 手机维修 & 配件销售（严格限定，不扩散品类） |
| **目标市场** | 爱尔兰本地（Ireland） |
| **商业形态** | B2B2C：平台（B）→ 加盟门店（B）→ 终端用户（C） |
| **盈利核心** | 向加盟门店按销售订单抽成 + 维修会员服务分润 |

## 三、核心角色

```
┌─────────────────────────────────────────────────────────┐
│                       IERepair 平台                      │
│                                                         │
│  ┌──────────┐    ┌──────────────┐    ┌───────────────┐  │
│  │  供应商   │───▶│  产品母库    │───▶│   加盟门店    │  │
│  └──────────┘    └──────────────┘    └───────┬───────┘  │
│                                              │           │
│                                              ▼           │
│                                       ┌───────────┐      │
│                                       │  终端用户  │      │
│                                       └───────────┘      │
└─────────────────────────────────────────────────────────┘
```

### 3.1 平台方（Super Admin）
- 维护产品母库（与供应商对接，保持品类纯洁性）
- 管理加盟门店的入驻、审核、停用
- 配置抽成规则和结算周期
- 管理维修会员计划
- 查看全平台数据报表

### 3.2 供应商（Supplier）
- 提供商品 SKU 及报价
- 维护库存状态
- 接收门店订单后履约发货

### 3.3 加盟门店（Merchant）
- 从产品母库中选择自己要销售的商品
- 自主设定门店售价（不允许低于平台最低建议价）
- 管理门店基础信息（营业时间、地址、联系方式）
- 接收用户订单 & 维修预约
- 查看门店结算报表
- **不允许添加平台母库以外的商品**

### 3.4 终端用户（Consumer）
- 搜索附近门店 / 搜索产品
- 浏览商品详情、比价
- 下单购买（到店自取 or 邮寄）
- 在线预约手机维修
- 购买维修会员计划（碎屏险等）
- 管理个人订单、会员权益

## 四、商业模式

### 4.1 收入来源

| 收入类型 | 说明 | 计费方式 |
|----------|------|----------|
| **销售抽成** | 用户通过平台在门店下单，平台按订单金额抽成 | 按比例（建议 5%~15%，可按品类差异化） |
| **维修服务分润** | 用户通过平台预约维修，平台收取服务费或分润 | 固定服务费 or 按比例 |
| **会员计划** | 用户购买碎屏险等年度会员，平台与门店分润 | 按维修次数结算给门店 |
| **未来可选** | 门店广告位排名、增值功能订阅 | 独立计费（初期不做） |

### 4.2 成本结构

| 成本项 | 说明 |
|--------|------|
| 平台研发与运维 | 一次性开发 + 持续运维 |
| 产品母库维护 | 与供应商对接、数据清洗、品类审核 |
| 市场推广 | SEO、Google Ads、本地地推 |
| 客服支持 | 门店入驻支持、用户售后 |

### 4.3 对加盟门店的价值主张（为什么免费给他们用）

1. **引流**：平台聚合全爱尔兰用户搜索流量，门店坐享其成
2. **供应链**：接入平台即可获得稳定的批发货源（含大供应商优惠价）
3. **数字化管理**：免费获得订单管理、库存追踪、收款结算工具
4. **品牌背书**：加入 IERepair 联盟，提升用户信任度

## 五、品类管控策略（重要）

> 平台核心竞争力之一在于"品类纯洁性"。只聚焦手机相关品类，确保用户搜索体验高度精准。

**允许的品类（白名单制）：**
- 手机维修服务（换屏、换电池、主板维修等）
- 手机保护配件（手机壳、钢化膜、防摔膜等）
- 充电配件（充电器、数据线、充电宝等）
- 音频配件（耳机、蓝牙耳机等）
- 存储配件（内存卡、扩展存储等）
- 手机清洁工具

**明确禁止（黑名单）：**
- 无人机、电动滑板车、电动自行车
- 智能家居设备
- 与手机无关的电子产品
- 食品、服装等非电子类商品

**执行机制：**
- 加盟商只能从平台审核过的产品母库中选品，**没有自行添加商品的入口**
- 平台管理员对供应商提交的新品进行品类审核，不合格直接拒绝入库

## 七、平台发展路径（分阶段）

### Phase 1 — 验证期（0~3个月）
- 上线基础功能：产品搜索、门店展示、在线预约
- 以客户自有 3 家门店为试点
- 打磨产品母库初始数据（与核心供应商对接）

### Phase 2 — 扩张期（3~12个月）
- 向爱尔兰全境招募加盟商
- 上线支付 & 结算模块
- 推出维修会员计划
- SEO 优化 + Google Business 集成

### Phase 3 — 规模期（1年以上）
- 目标覆盖 500~3000 家门店
- 引入更多供应商竞价，降低门店进货成本
- 数据分析与智能选品推荐
- 考虑扩展到英国市场（UK）

## 八、关键成功要素

1. **产品母库质量**：覆盖全面、数据准确、更新及时
2. **门店密度**：用户搜索时附近必须有门店，否则流量无法转化
3. **用户端体验**：搜索快、结果精准、预约流程简单
4. **门店端极简**：让不懂技术的小店主也能在 10 分钟内完成开店配置
5. **品类纪律**：严守手机配件垂直赛道，不因短期利益破坏平台定位
