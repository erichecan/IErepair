# IERepair 平台 — 各端页面功能结构

> 文档版本：v1.0  
> 最后更新：2026-04-01

---

## 概述

平台共分四个独立前端入口：

| 入口 | 访问对象 | 形态 |
|------|----------|------|
| **用户端** | 终端消费者 | 响应式 Web（移动端优先）|
| **商家后台** | 加盟门店店主 / 店员 | Web（桌面端为主，兼容移动）|
| **供应商后台** | 供应商账号 | Web（桌面端）|
| **平台管理后台** | SuperAdmin | Web（桌面端）|

---

## 一、用户端（Consumer Web）

### 导航结构

```
首页
├── 搜索（全局入口）
├── 维修服务
├── 商品分类
├── 我的
└── 购物车（角标计数）
```

---

### 页面清单

#### 1.1 首页

| 区块 | 内容 |
|------|------|
| 搜索框 | 关键词输入 + Eircode 输入，一键搜索 |
| 快捷入口 | 换屏、换电池、手机壳、充电器、会员购买 |
| 附近门店 Banner | 基于用户上次使用的 Eircode，展示最近 3 家门店 |
| 热门商品 | 平台推荐商品（全平台销量前 20） |
| 会员计划宣传栏 | 引导购买碎屏险等会员套餐 |

---

#### 1.2 搜索结果页

| 区块 | 内容 |
|------|------|
| 搜索条件栏 | 关键词、Eircode（可修改）、筛选按钮 |
| 筛选面板 | 品类、价格区间、营业状态（营业中）、距离范围 |
| 排序方式 | 距离最近 / 价格最低 / 评分最高 |
| 结果列表 | 商品卡（图片、名称、规格）+ 每家在售门店的价格对比 |
| 无结果状态 | 提示"附近无门店在售"+ 推荐扩大距离范围 |

**商品卡信息：**
- 商品图片、名称、适配机型
- 最低价格起（展示附近价格区间）
- 在售门店数量
- 点击进入商品详情页

---

#### 1.3 商品详情页

| 区块 | 内容 |
|------|------|
| 商品信息 | 图片轮播、名称、品牌、规格、商品描述 |
| 在售门店列表 | 门店名称、距离、该门店售价、营业状态、"选择此店"按钮 |
| 门店筛选 | 按 Eircode 距离排序，可输入新 Eircode 重新搜索 |
| 会员提示 | 若为维修类商品，展示"持会员可免费/折扣享受此服务" |

---

#### 1.4 门店详情页

| 区块 | 内容 |
|------|------|
| 门店基础信息 | 店名、地址、Eircode、电话、营业时间 |
| 地图展示 | 嵌入 Google Maps 静态地图，标注门店位置 |
| 用户评分 | 星级 + 评论数（预留，初期可不上线） |
| 在售商品列表 | 本店上架的全部商品，支持品类筛选 |
| 维修服务列表 | 本店提供的维修类型及价格 |
| "预约维修"按钮 | 快速跳转维修预约流程 |

---

#### 1.5 购物车

| 区块 | 内容 |
|------|------|
| 购物车列表 | 商品、数量、单价、所属门店 |
| 注意事项 | 不同门店商品需分开结算（不支持跨店合并支付）|
| 小计 | 含商品金额、平台服务费（若有）|
| 去结算按钮 | 跳转至结算页 |

---

#### 1.6 结算页

| 区块 | 内容 |
|------|------|
| 取货方式选择 | 到店自取（选日期时间段）/ 邮寄（填收货地址）|
| 价格明细 | 商品金额 + 邮费（邮寄时）|
| 支付方式 | Stripe 在线支付（信用卡 / Apple Pay / Google Pay）/ 到店支付 |
| 提交订单按钮 | 确认后跳转 Stripe 支付页或生成待支付订单 |

---

#### 1.7 维修预约页

| 步骤 | 内容 |
|------|------|
| Step 1 | 选择手机品牌（Apple / Samsung / Huawei / 其他）|
| Step 2 | 输入 / 选择机型（如 iPhone 14 Pro）|
| Step 3 | 选择维修类型（换屏 / 换电池 / 进水 / 其他）|
| Step 4 | 输入 Eircode，系统展示附近可提供此服务的门店 |
| Step 5 | 选择门店 + 选择预约时间段 |
| Step 6 | 确认信息（含会员抵扣提示）|
| Step 7 | 提交预约 → 支付定金（可选）或直接确认 |

---

#### 1.8 个人中心

```
个人中心
├── 我的订单
│   ├── 全部订单
│   ├── 待支付
│   ├── 处理中
│   ├── 待自取 / 配送中
│   └── 已完成
├── 我的预约
│   ├── 待确认
│   ├── 已确认
│   └── 历史预约
├── 我的会员
│   ├── 当前套餐
│   ├── 剩余次数 & 有效期
│   ├── 使用记录
│   └── 升级 / 续费
├── 账户设置
│   ├── 修改手机号
│   ├── 绑定 / 解绑 Google / Apple
│   ├── 收货地址管理
│   └── 通知设置
└── 帮助 & 客服
```

## 二、商家后台（Merchant Dashboard）

### 导航结构

```
商家后台
├── 工作台（首页概览）
├── 订单管理
├── 预约管理
├── 商品管理
├── 门店设置
├── 财务结算
└── 采购建议
```

---

### 页面清单

#### 2.1 工作台（首页）

| 区块 | 内容 |
|------|------|
| 今日数据 | 今日订单数、今日营业额、待处理订单数、待确认预约数 |
| 快捷操作 | 处理新订单、确认预约、查看结算 |
| 公告栏 | 平台最新通知（新品入库、规则变更等）|
| 采购提醒 | 本周采购建议提示（红点提醒）|

---

#### 2.2 订单管理

| 功能 | 说明 |
|------|------|
| 订单列表 | 按状态筛选（待处理 / 处理中 / 已完成 / 已取消）|
| 订单详情 | 商品、用户联系方式、取货方式、支付状态 |
| 接单 / 拒单 | 一键操作，拒单需填写原因 |
| 核销到店自取 | 扫描用户二维码 or 输入订单号完成核销 |
| 填写快递信息 | 邮寄订单填写快递公司 + 单号 |
| 搜索 & 导出 | 按日期、状态筛选，导出 CSV |

---

#### 2.3 预约管理

| 功能 | 说明 |
|------|------|
| 预约日历视图 | 按日/周查看预约分布 |
| 预约列表 | 待确认 / 已确认 / 已完成 / 已取消 |
| 预约详情 | 用户信息、手机型号、维修类型、预约时间 |
| 接受 / 拒绝预约 | 拒绝需填原因，系统通知用户 |
| 完成核销 | 维修完成后核销，触发会员权益结算（如适用）|
| 维修记录填写 | 记录实际维修内容、收费金额（到店支付）|

---

#### 2.4 商品管理

| 功能 | 说明 |
|------|------|
| 已上架商品列表 | 展示本店在售商品、价格、上架状态 |
| 从母库选品 | 按品类/品牌/关键词浏览母库，勾选添加 |
| 修改售价 | 单个修改 or 批量调价（不得低于平台最低价）|
| 下架商品 | 将商品从本店移除（不影响母库）|
| 维修服务管理 | 设置本店提供的维修类型及报价（从平台维修服务库选择）|

> **注意**：无"添加自定义商品"入口，所有商品必须来自产品母库。

---

#### 2.5 门店设置

| 功能 | 说明 |
|------|------|
| 基础信息 | 店名、地址、Eircode、电话、简介、Logo 上传 |
| 营业时间 | 按星期设置每日开关店时间 |
| 预约时间段设置 | 设置可预约的时间粒度（如每 30 分钟一个时间段）|
| 每日最大预约数 | 防止超量接单 |
| 账号安全 | 修改密码、绑定手机号 |

---

#### 2.6 财务结算

| 功能 | 说明 |
|------|------|
| 收入概览 | 本月 / 上月总营业额、平台抽成、实际到账 |
| 订单流水 | 每笔订单金额、抽成扣除、净收入 |
| 月度账单 | 下载 PDF / CSV 对账单 |
| 应付账单（到店支付订单抽成）| 查看待缴抽成金额，通过平台转账支付 |
| 银行账户设置 | 绑定 IBAN，用于接收线上支付结算款 |

---

#### 2.7 采购建议

| 功能 | 说明 |
|------|------|
| 建议清单 | 系统生成的建议采购商品、建议数量、参考供应商价格 |
| 一键联系供应商 | 跳转平台采购渠道 or 显示供应商联系方式 |
| 历史建议记录 | 查看过去的采购建议 |

---

## 三、供应商后台（Supplier Portal）

### 导航结构

```
供应商后台
├── 工作台
├── 商品管理
│   ├── 已入库商品
│   └── 待审核商品
├── 订单 / 采购单
├── 库存管理
└── 账户设置
```

#### 3.1 商品管理

| 功能 | 说明 |
|------|------|
| 提交新品申请 | 填写商品信息（名称/品牌/规格/图片/批发价/适配机型）|
| 审核状态查看 | 查看各商品审核进度（待审核 / 通过 / 拒绝+原因）|
| 修改已入库商品 | 更新价格、图片、描述（修改需重新审核）|
| 商品列表 | 批发价、入库状态、在售门店数量 |

#### 3.2 库存管理

| 功能 | 说明 |
|------|------|
| 库存数量维护 | 按 SKU 维护当前可供货库存数量 |
| 低库存预警设置 | 设置预警阈值，触发后自动通知平台 |
| 库存变更记录 | 出货记录、补货记录 |

#### 3.3 订单 / 采购单

| 功能 | 说明 |
|------|------|
| 采购单列表 | 门店或平台发起的采购需求 |
| 确认发货 | 填写快递信息，更新发货状态 |
| 历史交易记录 | 查看回款情况 |

---

## 四、平台管理后台（SuperAdmin）

### 导航结构

```
管理后台
├── 数据大盘
├── 门店管理
│   ├── 入驻审核
│   ├── 已加盟门店
│   └── 暂停 / 注销门店
├── 产品母库
│   ├── 商品审核队列
│   ├── 全部商品
│   └── 品类管理
├── 供应商管理
├── 用户管理
├── 订单管理（全平台）
├── 维修会员管理
│   ├── 套餐配置
│   └── 会员使用记录
├── 财务管理
│   ├── 抽成规则配置
│   ├── 月度结算
│   └── 门店应付款追踪
├── SMS / 通知管理
└── 系统设置
```

---

#### 4.1 数据大盘

| 指标 | 说明 |
|------|------|
| 全平台 GMV | 今日 / 本月 / 历史 |
| 门店数量 | 已激活 / 申请中 / 暂停 |
| 用户数量 | 注册用户 / 活跃用户（30日）|
| 订单数量 | 各状态分布 |
| 平台收入 | 抽成收入趋势图 |
| 热销商品 TOP 10 | 全平台维度 |
| 热门维修类型 | 换屏 / 换电池等分布 |

---

#### 4.2 门店管理

| 功能 | 说明 |
|------|------|
| 入驻申请审核 | 查看申请资料、核验营业执照、一键通过/拒绝 |
| 门店列表 | 搜索、筛选（城市/状态）、查看详情 |
| 门店详情 | 基础信息、销售数据、在售商品数、结算状态 |
| 暂停门店 | 违规或投诉处理时临时停用门店 |
| 抽成比例设置 | 可按门店或按品类单独设置抽成率 |

---

#### 4.3 产品母库管理

| 功能 | 说明 |
|------|------|
| 审核队列 | 供应商提交的待审核商品，逐一审核 |
| 审核操作 | 通过（入库）/ 拒绝（填写原因，退回供应商）|
| 全部商品 | 搜索、筛选、上架/下架、编辑（平台可直接编辑）|
| 品类管理 | 维护白名单品类树（增删改查）|
| 最低售价设置 | 为每个商品设置平台最低建议零售价 |

---

#### 4.4 维修会员套餐管理

| 功能 | 说明 |
|------|------|
| 套餐列表 | 查看现有套餐配置 |
| 创建 / 编辑套餐 | 名称、价格、有效期、权益（次数/折扣/机型限制）|
| 套餐上下架 | 控制用户端展示 |
| 会员统计 | 各套餐购买量、活跃会员数、到期预警 |
| 维修核销记录 | 查看各会员在各门店的使用明细 |

---

#### 4.5 财务管理

| 功能 | 说明 |
|------|------|
| 抽成规则配置 | 按品类设置抽成比例（支持差异化）|
| 月度结算 | 生成月度账单，触发 Stripe 自动结算 |
| 门店应付账单 | 追踪到店支付订单的应收抽成，标记已付 / 逾期 |
| 平台收入报表 | 按时间、品类、门店维度汇总 |

---

## 五、页面数量汇总

| 端 | 主要页面数 |
|----|-----------|
| 用户端 | ~15 个核心页面 |
| 商家后台 | ~10 个核心页面 |
| 供应商后台 | ~6 个核心页面 |
| 平台管理后台 | ~12 个核心页面 |
| **合计** | **~43 个核心页面** |

> 不含登录/注册/404/通用弹窗等基础页面。
